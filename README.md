# Vax-Dealers: прогноз выработки ВЭС

Проект для HackAlem AI прогнозирует **среднюю нормализованную мощность двух турбин на каждый час следующих 48 часов**. Агент получает архивные прогнозы погоды, проверяет их, запускает модель и сохраняет результат. Тестовый период: февраль 2026 года.

**Начните здесь:** [готовые результаты](results/forecast_results.zip), [как устроен расчёт](docs/methodology.md), [что исправлено](docs/changes.md).

## Быстрый запуск

Нужен **Python 3.12**. Команды выполняются из корня этого приватного репозитория.

Создайте папку `raw/` и положите туда два CSV организаторов. Имена должны оканчиваться на `turbine 1.csv` и `turbine 2.csv`.

Windows PowerShell:

~~~powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe wind_agent.py run
~~~

Linux / macOS:

~~~bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python wind_agent.py run
~~~

`run` выполняет весь цикл: подготовку CSV, загрузку погоды, обучение, проверку на январе, ежедневные прогнозы за февраль и упаковку результатов. Первая загрузка требует интернета. Повторный запуск по готовому кэшу: `python wind_agent.py run --offline`.

В командах ниже `python` означает Python из созданного окружения. Активировать окружение необязательно: можно продолжать использовать полный путь к нему.

## Что получится

Архив [forecast_results.zip](results/forecast_results.zip) содержит папку `results/`. Он позволяет посмотреть результаты без установки Python. Бинарная модель для нового расчёта создаётся командой `train` или `run`.

| Файл | Содержимое |
|---|---|
| `results/submission_february.csv` | 1 344 строки: 672 часа февраля на каждую турбину, один прогноз на сутки вперёд |
| `results/forecasts_48h.csv` | 2 784 строки: 29 выпусков × 48 часов × 2 турбины; последние выпуски заходят в март |
| `results/station_february.csv` | Две турбины рядом; среднее станции при допущении равной номинальной мощности |
| `results/run_summary.json` | Число прогнозов, резервных значений, отпечатки модели и входов |
| `reports/january_metrics.csv` | Проверка точечного прогноза на январе и сравнение с простыми методами |
| `reports/data_audit.json` | Пропуски, полные часы и контрольные суммы исходных CSV |
| `reports/model_card.json` | Параметры, границы обучения и калибровка диапазонов |

`prediction` — число в шкале нормализованной мощности 0–1. Это **не МВт и не МВт·ч**. `status=weather_model` означает расчёт по погоде; `fallback_climatology` — историческое среднее из-за отсутствующих или некорректных погодных данных.

## Проверенное качество

Результат повторного расчёта на январе 2026. MAE — средняя абсолютная ошибка; меньше значит лучше. Значение 0,20 означает ошибку 0,20 в шкале 0–1, а не «точность 80%».

| Турбина | Горизонт | MAE модели | MAE исторического среднего | MAE последнего доступного значения |
|---|---|---:|---:|---:|
| 1 | 1–24 ч | 0,203261 | 0,302316 | 0,320750 |
| 2 | 1–24 ч | 0,205077 | 0,303714 | 0,325995 |
| 1 | 25–48 ч | 0,227042 | 0,300836 | 0,362604 |
| 2 | 25–48 ч | 0,230893 | 0,302357 | 0,362664 |

Январь исключён из обучения и выбора параметров точечной модели. Его ошибки используются для диапазонов `lower90`/`upper90`, поэтому январь не является независимой проверкой покрытия этих диапазонов. Фактических февральских измерений в предоставленных CSV нет; точность на феврале не заявляется.

## Отдельные команды

~~~bash
python wind_agent.py status
python wind_agent.py prepare --data-dir raw
python wind_agent.py fetch
python wind_agent.py train
python wind_agent.py replay --offline
python wind_agent.py package
python -m unittest discover -s tests -v
~~~

Расчёт одного дня:

~~~bash
python wind_agent.py replay --first-issue 2026-02-10 --last-issue 2026-02-10
~~~

Агент загрузит отсутствующие месяцы. `--refresh` обновит кэш; `--offline` запретит сетевые запросы. Эти параметры нельзя совмещать. Отдельный день сохраняется в `results/cycles/`, несколько выбранных дней — в `results/runs/`. Частичный запуск не перезаписывает полный февраль.

Проверка обновлений выбранного исторического выпуска:

~~~bash
python wind_agent.py watch --issue-date 2026-02-10 --interval-seconds 3600
~~~

Остановка — Ctrl+C. При неизменившихся входах новый расчёт не выполняется. Журнал: `results/agent_events.jsonl`. Это воспроизведение архива, а не подключение к действующей электростанции.

## Условия, которые нужно подтвердить

- В `config.json` принят **UTC+5**, выпуск в 23:00 местного времени. Часовой пояс и то, что метка означает начало десятиминутного интервала, организаторами не подтверждены. `time_assumptions_confirmed=false` сохраняется в отчётах. После изменения настроек модель нужно обучить заново.
- Источник — [Open-Meteo Previous Runs / NOAA GFS](https://open-meteo.com/en/docs/previous-runs-api). Это архив прогнозов. API не возвращает фактическое историческое время публикации выпуска. Применяется допущение о задержке 12 часов; строгая доказуемость доступности остаётся ограничением.
- `--require-verified-availability` намеренно останавливает `replay`: текущий источник не подтверждает это условие. Для строгой проверки нужен архив исходных выпусков с подтверждённой доступностью.
- Высота ступицы, номинальные мощности и признаки ремонтов неизвестны. Ветер на 80 м — признак погодной модели, а не утверждение о высоте турбин.

Полный разбор: [методика и ограничения](docs/methodology.md). Источник погодных данных: Open-Meteo и NOAA; атрибуция CC BY 4.0, условия API — на сайте провайдера.

## Где находится код

| Файл | Назначение |
|---|---|
| `wind_agent.py` | Подготовка измерений, обучение, агент, команды запуска |
| `weather_archive.py` | Загрузка, проверка и чтение погодного кэша |
| `config.json` | Часовой сдвиг и допущение о задержке публикации |
| `tests/` | Проверки временных границ, пропусков, кэша и резервного режима |
| `docs/` | Методика и список исправлений |
| `reports/` | Проверяемые результаты запуска |
| `results/` | Архив почасовых прогнозов |

Исходные CSV, погодный кэш, временные файлы и бинарная модель исключены из Git. Все изменения ведутся в приватном репозитории команды Vax-Dealers.
